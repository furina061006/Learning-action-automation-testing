# README
本模块的题目都在[./exercises](./exercises)
但在做题前, 没有基础的同学推荐先阅读[命令行入门指南](./命令行入门指南.md)喵.

> <span style="color:red">注:</span>
> 1. 希望能**全程命令行**哦;
> 2. **别动`exercises`目录内除.`bash`外的所有文件喵**, 到时候发现你的答案和标准答案不一样就难办了喵();
> 3. `.bash`内**命令行根目录**定为 **该`.bash`文件所在目录**
> 4. 写完`./bash`文件**记得执行**一下, 看下输出是否与同目录的`answer.txt`一致, 如果遇到`./bash`文件无法执行, 自行学习如何增加执行权限
