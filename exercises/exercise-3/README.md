## 题3: 编译多源文件的C语言项目
### 题目描述:
该目录下有多个C语言的源程序文件, 需要你使用`gcc`命令将其该项目成功编译到`./dev/debug`目录下, 并且运行它
**请将正确的命令行~(包括编译和运行)~写在本目录的`.bash`文件中**.
正确答案的输出于本目录的answer.txt文件中~

> <span style="color:red">注:</span>
> 这题建议大家做题前, 使用`gcc --help` 命令行,学习一下gcc相关参数和用法, 以后遇到陌生的命令也记得用`--help`or`--man`选项去了解该命令.
> 自己的信息筛选能力也很重要, 一昧地使用AI工具而自己没有信息获取和独立思考, 得到的答案永远只是浮于表面的二手结论。
